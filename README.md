# Carlos · 30 Years — Website

A bilingual static website (German/Spanish) for Carlos's 30th birthday celebration.

## Files
- `index.html`: homepage, party information, and frequently asked questions.
- `wishlist.html`: separate wishlist page.
- `styles.css`: responsive design for mobile devices.
- `script.js`: language selector, mobile menu, and wishlist integration.
- `assets/`: generated banner without text and logo.
